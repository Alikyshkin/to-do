# Список дел

Браузерный список задач на HTML, CSS и JavaScript. Откройте `index.html` в браузере. Сборка и внешние сервисы не нужны.

- Добавляйте задачи, отмечайте выполненные и выбирайте нужный фильтр.
- «Изменить» открывает поле прямо в строке. `Enter` сохраняет текст, `Esc` отменяет изменения.
- Задачи сохраняются в этом браузере. В приватном окне или при отключённом хранилище сохранение может быть недоступно.
